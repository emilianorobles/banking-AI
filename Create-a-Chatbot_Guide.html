Basic AI Chatbot · Streamlit + LangChain

Build a Simple AI Chatbot

Create a lightweight chatbot that sends a user message directly to an LLM and displays the answer. It is ideal for general conversation, brainstorming, summarization, rewriting, explaining, translating, and ideation.

Start Building Check If This Fits

What This Tool Is For

A basic chatbot sends the user message directly to the AI model and shows the answer. It does not read files automatically.

Good Uses

  • General conversation
  • Brainstorming
  • Summarizing pasted text
  • Rewriting, explaining, translating, or ideating

What It Knows

  • What the model already knows
  • What the user types into the chat
  • Nothing from files unless the user pastes it

Minimal Stack

  • Streamlit for the interface
  • LangChain OpenAI for the model client
  • httpx for the custom connection

Know the Boundaries

This is the simplest useful chatbot pattern. It is powerful when the user supplies the context, but it is not a document assistant.

What This Bot Can Do

  • Answer general questions
  • Explain concepts
  • Summarize pasted text
  • Generate ideas
  • Help with writing

What This Bot Cannot Do

  • Answer questions about a PDF unless the user pastes the content
  • Search inside uploaded documents
  • Remember a company handbook, policy file, or research paper unless you add that capability separately
Decision rule If users need answers from uploaded files, policies, manuals, or research papers, this guide is not enough. You need a document search or retrieval-based guide.

Test Your API Key

Before building the app, confirm your key works with a small connectivity test.

Remember you can access your team API Key outside the team folder in the APIKey.xlsx file.

test_key.py 
import httpx
from langchain_openai import ChatOpenAI

client = httpx.Client(verify=False)

llm = ChatOpenAI(
    base_url="https://genailab.tcs.in",
    model="azure/genailab-maas-gpt-4.1",
    api_key="YOUR_PROVIDED_KEY_HERE",
    http_client=client
)

try:
    response = llm.invoke("Hi! Are you online?")
    print("CONNECTION SUCCESSFUL!")
    print("AI Response:", response.content)
except Exception as e:
    print("ERROR: Could not connect. Check your key or internet.")
    print(f"Details: {e}")

Build the Basic Chatbot

Create a file named app_basic.py. The app stores the chat history in the Streamlit session and sends each new user message to the model.

app_basic.py 
import os

os.environ["CURL_CA_BUNDLE"] = ""
os.environ["PYTHONHTTPSVERIFY"] = "0"

import httpx
import requests
import streamlit as st
from urllib3.exceptions import InsecureRequestWarning
from langchain_openai import ChatOpenAI

requests.packages.urllib3.disable_warnings(category=InsecureRequestWarning)

API_KEY = "YOUR_PROVIDED_KEY_HERE"
BASE_URL = "https://genailab.tcs.in"


@st.cache_resource
def get_llm():
    client = httpx.Client(verify=False)
    return ChatOpenAI(
        base_url=BASE_URL,
        model="azure/genailab-maas-gpt-4.1",
        api_key=API_KEY,
        http_client=client,
        temperature=0.7,
    )


def main():
    st.set_page_config(page_title="Basic AI Chatbot", layout="wide")
    st.title("Basic AI Chatbot")
    st.caption("Ask general questions and get AI-generated answers.")

    llm = get_llm()

    if "messages" not in st.session_state:
        st.session_state.messages = []

    for msg in st.session_state.messages:
        with st.chat_message(msg["role"]):
            st.markdown(msg["content"])

    user_input = st.chat_input("Type your message here...")

    if user_input:
        st.session_state.messages.append({"role": "user", "content": user_input})

        with st.chat_message("user"):
            st.markdown(user_input)

        with st.chat_message("assistant"):
            with st.spinner("Thinking..."):
                try:
                    response = llm.invoke(user_input)
                    answer = response.content
                    st.markdown(answer)
                    st.session_state.messages.append({
                        "role": "assistant",
                        "content": answer
                    })
                except Exception as e:
                    st.error(f"Error: {e}")


if __name__ == "__main__":
    main()
