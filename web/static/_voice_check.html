Voice diagnostics

Runs the same speech API the assistant uses and reports the raw failure, so “needs an internet connection” can be narrowed to the actual cause. Open this from the running app’s own address — e.g. http://127.0.0.1:5000/static/_voice_check.html.

The microphone test will ask for permission.

Check on-device speech is separate because the API behind it crashes the tab on some Chromium builds. If this page vanishes when you press it, that is the answer: no on-device speech in this browser.
