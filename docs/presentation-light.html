01 · The Problem

Banks are stuck choosing between safe and fast.

Every transaction, one slow lane

Sending everything through a human analyst — or a model — doesn't scale, and doesn't survive a live outage.

False positives punish good customers

Aggressive rules block legitimate spend abroad, on trips, at odd hours — eroding trust exactly when it matters most.

Queries scattered, unrouted

Balance checks, disputes, fraud reports and travel flags all land in the same queue with no triage.

Decisions nobody can explain

"The model flagged it" isn't good enough for a regulator, analyst, or customer — there's no citation, no audit trail.

02 · The Solution

A layered pipeline that calls the LLM only when it earns its keep.

BedRock Financial routes every transaction through deterministic rules first, escalates the genuinely ambiguous ~4% to a RAG-grounded fraud analyst agent, and gives customers & analysts a real-time dashboard for everything in between.

05 · Under the Hood

The blend that stops the model from piling on.

Measured on the eval harness: a symmetric blend left recall at 100% but pushed the average risk score on legitimate customers from 19.1 → 24.9. core/pipeline.py:80-116

core/pipeline.py 
# Asymmetric blend weights. See _blend() for the reasoning.
LLM_WEIGHT_EXCULPATORY = 0.65   # model argues the transaction is SAFER than rules think
LLM_WEIGHT_INCRIMINATING = 0.25  # model argues it is MORE dangerous


def _blend(rule_score: int, llm_score: int) -> int:
    """Combine the deterministic and model scores -- asymmetrically, on purpose.

    The rules are already excellent at DETECTING risk (100% recall).
    They need no help finding fraud, so an incriminating opinion from
    the model is discounted heavily -- it can nudge, not drive.

    What rules cannot do is EXONERATE. So when the model argues a
    transaction is safer than the rules think, we listen closely.
    """
    weight = (LLM_WEIGHT_EXCULPATORY if llm_score < rule_score
              else LLM_WEIGHT_INCRIMINATING)
    blended = round((1 - weight) * rule_score + weight * llm_score)

    # Physics beats opinion: a very high rule score still sets a floor.
    if rule_score >= 90:
        blended = max(blended, rule_score)
    return max(0, min(100, int(blended)))
